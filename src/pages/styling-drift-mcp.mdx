# Styling Drift MCP

<p class="lede">A tool that teaches AI coding assistants the design system — and tells them when they're drifting off it.</p>

## What it does

The Styling Drift MCP is a small server that AI coding assistants (Claude Code, Cursor, and other MCP-aware clients) can call while writing React Native code. It encodes the project's design-system judgment — spacing scale, type ramp, color tokens, component conventions — as tools the model can invoke before committing a change.

The result: consistency is enforced where it's cheapest, in the loop where code is being written, rather than patched up later in design review.

## Why I built it

I wrote it alongside [Dog Mode](/dog-mode) — a production iOS app I built mostly with Claude Code. The model was excellent at shipping features, but on its own it would quietly invent new spacing values, repaint with off-brand colors, and reintroduce styles I'd already consolidated. Catching it in code review worked, but it was slow and demoralizing.

Pushing the design system into an MCP tool fixed the loop. The model now asks the system what's allowed before guessing.

## What's interesting about it

- **Design-as-code, but bidirectional.** The same tokens that ship to production also constrain the model.
- **Cheap to extend.** New rules are small functions — not prompt-engineering or fine-tuning.
- **A pattern, not a product.** The interesting part is the shape of the tool, not the specific React Native bindings. The same approach generalizes to any codebase with an opinionated system.
