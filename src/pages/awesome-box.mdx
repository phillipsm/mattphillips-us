# Awesome Box

<p class="lede">An alternate returns box that sits alongside your library's regular book drop.</p>

<img src="/assets/awesome-box/ab-core-med.jpg" alt="An Awesome Box positioned next to a regular library drop box" />
<p class="img-desc">The Awesome Box sits next to the regular drop box. Return to one box or the other.</p>

## The Idea

If you're returning an item you really connected with, drop it in the Awesome Box instead of the regular book drop. Library staff tag it as Awesome and share it with the rest of the community.

The key feature is that it doesn't ask the user to significantly alter their behavior — they're already returning the item to the library. We're just asking them to choose between two boxes. No accounts, no reviews to write. A physical vote.

## Off Into the Sunset

Annie Cain and I built the Awesome Box together at the [Harvard Library Innovation Lab](https://lil.law.harvard.edu/). We learned a lot from it, but in 2016 we decided to turn off the awesomebox.io website to free up energy for other projects.

Thank you so much, 500+ partner libraries. What a great run.
