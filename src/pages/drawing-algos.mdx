# Drawing with Algorithms

<p class="lede">Set up the guardrails and let the machine run. It doesn't grow weary.</p>

<img src="/assets/drawing-algos/drawing-algos-hero@2x.png" alt="Drawing with algorithms — generative pattern" />

## The Project

Patterns built by algorithm can be beautiful in print and make a natural fit for backgrounds, screen art, and information-rich display systems. Below are three recent sketches, made while I was searching for backgrounds for a wall-mounted display. Each runs live on the page.

## Keep Moving

<div id="canvas-container-a" class="sketch">
  <img src="/assets/drawing-algos/placeholder.png" class="placeholder-image" alt="Loading sketch…" />
</div>

This visual grows slowly — an accretion of color-shifting threads. A wobbly line is drawn across the canvas as a circle moves steadily on the x axis and bounces 80 times a second on the y axis.

## Monday

<div id="canvas-container-b" class="sketch">
  <img src="/assets/drawing-algos/placeholder.png" class="placeholder-image" alt="Loading sketch…" />
</div>

A message hides in the noise and scrolls past. What does it say? Two things get drawn to this canvas: red horizontal lines every 10 milliseconds, and a single letter every one second.

<p class="tile-desc"><a href="https://github.com/phillipsm/mattphillips-us/blob/master/assets/js/monday.js" target="_blank" rel="noopener">View source</a></p>

## Sink

<div id="canvas-container-c" class="sketch">
  <img src="/assets/drawing-algos/placeholder.png" class="placeholder-image" alt="Loading sketch…" />
</div>

The simplest of the three: one line between two random points, 80 times a second. The [p5.js `random()` function](https://p5js.org/reference/#/p5/random) makes it easy to pull a color from a list of colors for each line drawn.

<p class="tile-desc"><a href="https://github.com/phillipsm/mattphillips-us/blob/master/assets/js/sink.js" target="_blank" rel="noopener">View source</a></p>

## Tools and Role

I used the JavaScript visualization library [p5.js](https://p5js.org/) to manage logic and to interact with the `<canvas>` element. The familiar [`setup()` / `draw()` pattern](https://p5js.org/learn/program-flow.html) makes it quick to get something interesting on screen.

<p class="role-line"><strong>Role.</strong> JavaScript Developer.</p>
