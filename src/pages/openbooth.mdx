# OpenBooth

A photo booth built on a Raspberry Pi. This file is **Markdown** — Astro's MDX
integration turns it into a real HTML page at build time.

## What MDX gives you over plain Markdown

You can write normal prose, *italics*, **bold**, [links](https://mattphillips.us),
images:

![Placeholder](https://placehold.co/600x300)

…and when prose isn't enough, you can drop in components or raw HTML inline:

<aside style="border-left: 3px solid #888; padding-left: 1rem;">
  This is a custom block. In real case studies it might be an image gallery,
  a video embed, or an annotated diagram.
</aside>

That's the whole point: 90% of a case study is plain text, but the 10% that
needs structure gets it without leaving the file.
